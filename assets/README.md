# 品牌素材

`milliken-logo-blue.png` 沿用本工作区同一美利肯项目的 `github-pages-milliken/assets/milliken-logo-blue.png` 手写体标识，去除白色背景并统一为蓝色 #00378C，保留源字形与抗锯齿边缘，输出 RGBA 透明 PNG（395 × 120）。该蓝色与源项目 Logo 蓝底的主要像素色值一致。

`../favicon.png` 从同一标识截取首字母，用于浏览器图标。Logo 与主题均由仓库本地文件提供，不请求外部图片地址。

`milliken-monogram-blue.png` 直接从上述透明 Logo 截取手写首字母 M（源图裁剪框 12,22–100,107），保留原字形倾斜及透明背景。管理总览横幅以浅白色水印展示同一字形，无字体替代或额外旋转。
