# V2.1 多维学习成长驾驶舱

本版根据反馈，将经销商个人、经销商公司、美利肯员工放到一级管理视角，员工侧保留内部部门与岗位分析，同时保留原有业务专题。所有数据均模拟，后台功能依据沿用第一版的11页核验与操作手册V1.2；不更改原业务后台。

## 信息架构

|管理视角|核心问题|输出与下钻|
|---|---|---|
|管理总览|当前学习覆盖如何，哪些组织需要支持？|三类对象入口、学习趋势、关注名单、公司与部门表现、经销商公司明细|
|经销商个人|谁在学习，哪些课程主题未完成？|课程主题完成进度、学习跟进名单、个人任务/考试/成长明细、同公司基准|
|经销商公司|哪些公司团队参与不足，差异在哪里？|最多三家公司对比、公司×课程主题热力图、覆盖/完成/通过/人均时长、公司→团队成员→个人档案|
|美利肯员工|内部部门、岗位的必修任务是否达成？|部门×课程主题、部门必修排行、岗位学习覆盖、员工档案、同部门基准|

课程、智库、考试、学员成长、智库内容管理五个专题继续保留，并接受相同人群与日期筛选。管理总览与五个专题共用原有业务事实，避免两套指标。

## 人员与组织模型

- 模拟人员共360人：300位经销商人员归属12家经销商公司；60位员工归属独立的“美利肯中国（示例）”。
- 经销商不区分岗位，人员按所属公司查看学习、考试、成长记录。
- 员工部门：销售与渠道部、产品与技术部、市场与品牌部、客户服务部、培训与发展部。
- 员工岗位：区域经理、产品专员、市场专员、客户顾问、培训讲师。示例里每部门对应一种主要岗位；正式接入应读取人员档案，不在前端固定映射。
- 取消地理区域划分、区域对比和区域字段。公司视角只计算经销商人员。
- 进入经销商个人/公司时固定经销商身份；进入员工视角时固定员工与内部组织。切换视角保留日期，重置企业、身份及员工部门与岗位；专题页可自行选择人群。
- 这些视角是Demo分析范围，不构成生产数据权限控制。真实上线需要后端按登录身份及组织授权返回数据。

## 统计口径

|指标|计算方式|
|---|---|
|覆盖学员|截至期末已注册、符合当前所有筛选的去重人员|
|覆盖经销商公司|匹配人群涉及的经销商公司去重数，空公司不计入|
|课程学习覆盖率|本期有课程学习分钟数的人数 / 当前人员总数|
|课程任务完成率|本期分配且截至期末完成的任务数 / 本期分配任务数|
|必修任务达成率|本期分配的必修任务完成数 / 本期必修分配数|
|课程考试通过率|本期任务对应学员×试卷的最新成绩通过数 / 已参考数|
|人均学习时长|本期课程学习分钟 / 60 / 当前人员数，包含未学习人员|
|学习主题热力图|各公司/员工部门在课程分类下的任务完成率；展示完成/分配数，无任务显示“—”|
|同公司/同部门基准|当前筛选中同组织成员的完成任务合计 / 分配任务合计，含本人|

比率在公司、部门聚合时以实际分子和分母计算，不平均个人百分比；没有任务时数值卡显示0%，必须结合分母判断，热力图明确区分“无任务”。不生成无依据的综合能力评分，课程完成率不直接等同实际业务能力。

公司对比选择最多3家，继承日期、企业条件；可全部取消、重新选择。筛选后不匹配的公司自动退出对比。初次进入默认选择完成率最高的两家公司，仅用于展示操作。

任务、考试采用本期分配批次，行为量采用本期发生，等级/累计学分/成长值/勋章采用期末快照。环比为前一等长区间。人员档案中的课程认证仅指演示课程考试通过，不代表另行颁发的外部职业证书。

## 年度筛选与术语

快捷日期包括近7天、近30天、本月、本季度、本年度。“本年度”从演示年份的1月1日起，到演示数据截止日2026-10-23。原先的181天限制已取消。模拟明细自2026-04-01起，年度页面和导出都标明数据性质，页面额外提示明细起点。前一等长区间完全早于数据起点时，比较显示“暂无可比数据”。

“智库内容管理”对应原后台的智库投稿审核、内容配置、内容修改日志和用户协议管理：看投稿待审、通过/驳回、附件解析成功/失败、修改记录和协议状态。该页是上述功能的统计汇总，不新增一套审核业务流程。

## 交互和交付

个人档案包含基本归属、任务完成、必修进度、最新考试、同组织比较、成长值、学分、等级、勋章与本期流水。公司、部门可打开人员名单，再进入个人档案。必修未完成、完成后待考、连续14天未活跃支持名单查看和导出，不执行催学或消息发送。

明细表支持搜索、分类、数值排序与分页。CSV导出包含日期、企业和身份；员工范围额外包含员工部门与岗位；经销商导出不包含岗位；明细导出保留搜索与分类条件。公司对比展示所选公司各自指标，页头导出为当前筛选人群指标汇总，表格导出为匹配公司全集。

视觉改为深色侧栏、暖白主画布、墨绿与陶橙重点、清晰的数字层次。桌面与390px移动屏幕分别验证；宽表格和热力图在容器内横向滚动。

## 正式接入待确认

人员主键、公司及员工部门/岗位字段、历史组织归属、跨公司任职、内部员工权限及离职状态，需要由业务接口明确。课程、试卷、激励、智库内容管理规则仍以《指标与接入说明》中的待确认事项为准，新增的部门与岗位均为演示主数据。
