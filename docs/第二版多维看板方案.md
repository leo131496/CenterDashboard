# V2.5 多维学习成长驾驶舱

本版根据反馈，将经销商个人、经销商公司、美利肯员工放到一级管理视角，员工侧保留销售区域分析，同时保留原有业务专题。所有数据均模拟，后台功能依据沿用第一版的11页核验与操作手册V1.2；不更改原业务后台。

## 信息架构

|管理视角|核心问题|输出与下钻|
|---|---|---|
|管理总览|当前学习覆盖如何，哪些组织需要支持？|三类对象入口、学习趋势、关注名单、公司与销售区域表现、经销商公司明细|
|经销商个人|谁在学习，哪些课程主题未完成？|课程主题完成进度、学习跟进名单、个人任务/考试/成长明细、同公司基准|
|经销商公司|哪些公司团队参与不足，差异在哪里？|最多三家公司对比、公司×课程主题热力图、覆盖/完成/通过/人均时长、公司→团队成员→个人档案|
|美利肯员工|销售区域的必修任务是否达成？|销售区域×课程主题、销售区域必修排行、区域学习覆盖、员工档案、同区域基准|

课程、智库、考试、学员成长、智库内容管理五个专题继续保留，并接受相同人群与日期筛选。管理总览与五个专题共用原有业务事实，避免两套指标。

## 人员与组织模型

- 模拟人员共360人：300位经销商人员归属12家经销商公司；60位员工归属独立的“美利肯中国（示例）”。
- 经销商不区分岗位，人员按所属公司查看学习、考试、成长记录。
- 员工销售区域：华南、西南。区域名称依据本次业务确认；各区人数与学习记录仍为模拟数据。
- 员工不再使用此前演示设定的部门、岗位分组；按销售区域查看覆盖、必修任务与课程考试。
- 经销商公司不配置地理分区；销售区域仅归属美利肯员工，公司视角只计算经销商人员。
- 进入经销商个人/公司时固定经销商身份；进入员工视角时固定员工与内部组织。切换视角保留日期，重置企业、身份及员工销售区域；专题页可自行选择人群。
- 这些视角是Demo分析范围，不构成生产数据权限控制。真实上线需要后端按登录身份及组织授权返回数据。

## 经销商人员筛选

顶部选择经销商公司后，「经销商人员」显示对应公司截至期末已注册的人员姓名及编号。支持按姓名或编号搜索候选名单，选中一人后应用到所有指标、图表、明细与导出；「全部人员」恢复公司全员范围。未选公司时提示先选择公司，员工视角不显示此入口。

切换公司、身份或视角，以及重置筛选时清除人员选择。结束日期早于选中人员的注册日时自动恢复全部人员。人员筛选与企业、身份、日期取交集，不能跨公司；单图条件继续继承该人员限制。导出注明姓名及唯一编号，同名人员通过编号区分。当前人员名单均为模拟数据。

## 统计口径

|指标|计算方式|
|---|---|
|覆盖学员|截至期末已注册、符合当前所有筛选的去重人员|
|覆盖经销商公司|匹配人群涉及的经销商公司去重数，空公司不计入|
|课程学习覆盖率|本期有课程学习分钟数的人数 / 当前人员总数|
|课程任务完成率|本期分配且截至期末完成的任务数 / 本期分配任务数|
|必修任务达成率|本期分配的必修任务完成数 / 本期必修分配数|
|课程考试通过率|本期任务对应学员×试卷的最新成绩通过数 / 已参考数|
|人均学习时长|本期课程学习分钟 / 60 / 当前人员数，包含未学习人员|
|学习主题热力图|各公司/员工销售区域在课程分类下的任务完成率；展示完成/分配数，无任务显示“—”|
|同公司/同区域基准|当前筛选中同组织成员的完成任务合计 / 分配任务合计，含本人|

比率在公司、销售区域聚合时以实际分子和分母计算，不平均个人百分比；没有任务时数值卡显示0%，必须结合分母判断，热力图明确区分“无任务”。不生成无依据的综合能力评分，课程完成率不直接等同实际业务能力。

公司对比选择最多3家，继承日期、企业条件；可全部取消、重新选择。筛选后不匹配的公司自动退出对比。初次进入默认选择完成率最高的两家公司，仅用于展示操作。

任务、考试采用本期分配批次，行为量采用本期发生，等级/累计学分/成长值/勋章采用期末快照。环比为前一等长区间。人员档案中的课程认证仅指演示课程考试通过，不代表另行颁发的外部职业证书。

## 年度筛选与术语

快捷日期包括近7天、近30天、本月、本季度、本年度。“本年度”从演示年份的1月1日起，到演示数据截止日2026-10-23。原先的181天限制已取消。模拟明细自2026-04-01起，年度页面和导出都标明数据性质，页面额外提示明细起点。前一等长区间完全早于数据起点时，比较显示“暂无可比数据”。

“智库内容管理”对应原后台的智库投稿审核、内容配置、内容修改日志和用户协议管理：看投稿待审、通过/驳回、附件解析成功/失败、修改记录和协议状态。该页是上述功能的统计汇总，不新增一套审核业务流程。

## 交互和交付

个人档案包含基本归属、任务完成、必修进度、最新考试、同组织比较、成长值、学分、等级、勋章与本期流水。公司、销售区域可打开人员名单，再进入个人档案。必修未完成、完成后待考、连续14天未活跃支持名单查看和导出，不执行催学或消息发送。

明细表支持搜索、分类、数值排序与分页。CSV导出包含日期、企业和身份；指定经销商人员时额外包含姓名和人员编号；员工范围额外包含员工销售区域；经销商导出不包含岗位；明细导出保留搜索与分类条件。公司对比展示所选公司各自指标，页头导出为当前筛选人群指标汇总，表格导出为匹配公司全集。

视觉使用美利肯蓝色主色（#00378C）、白色侧栏和浅蓝灰主画布，配透明背景的蓝色手写体 Logo。按钮、选中状态、图表、热力图与弹窗采用一致的蓝色体系，状态标签保留语义颜色。桌面与390px移动屏幕分别验证；宽表格和热力图在容器内横向滚动。

## 单图切换与独立分析

24张图表统一提供类型切换、单图筛选和图内导出。分布图支持环形/饼图/条形/柱状/数据表；趋势图支持折线/面积/柱状/数据表；排行和比率比较支持条形/柱状/数据表；公司、销售区域与主题交叉图支持热力图/数据表。不同组织的完成率、勋章覆盖人数等不构成互斥占比，因此不提供饼图。

样式按图记住在当前浏览器，刷新恢复，不跨账号/设备同步。单图条件仅在当前页面会话保留，刷新清除。单图条件基于顶部日期和人群进一步缩小，固定视角不可切到其他身份；销售区域仅在员工范围可选。课程考试图增加分类与课程，关键词图增加检索词，附件与审核解析图增加附件类型。

应用后仅当前图更新，标注「仅此图」与具体范围；相邻图、指标卡与页面明细保持各自范围。单图清除不改变图形偏好。全局范围收窄后，越界日期自动收窄、不兼容的人群条件移除，并提示调整。

图内导出复用图中分类和数值，携带日期、人群与业务条件。公司、销售区域条形图人员下钻及个人任务考试也继承图内范围。切换图形不改变统计口径、数值或导出结果。

## 正式接入待确认

人员主键、公司及员工销售区域字段、历史组织归属、跨公司任职、内部员工权限及离职状态，需要由业务接口明确。课程、试卷、激励、智库内容管理规则仍以《指标与接入说明》中的待确认事项为准，华南、西南是本次确认的销售区域，员工归属仍为演示主数据。
