# 美利肯学习成长中心数据看板

学习成长中心新增「数据看板」的 V2.0 多维交互 Demo。已登录核验现有后台五组菜单、11个页面，并结合《美利肯 学习成长中心 详细操作手册》V1.2整理功能范围。

**所有学员、企业、数值、规则及流水均为模拟数据。未连接真实业务接口，未修改原后台。** 课程与内容名称仅用于展示业务场景。

## 运行

直接打开 `index.html` 即可离线演示。推荐使用 Node.js 20+：

```sh
npm run dev
```

访问 http://127.0.0.1:4173 。应用运行不需要安装依赖、不访问外部CDN。页面可部署在任意静态服务器或 GitHub Pages 的仓库子目录。

## 以管理对象组织看板

新版先选择管理视角，再分析业务专题：

|视角|内容|
|---|---|
|管理总览|个人/公司/员工入口、学习趋势、跟进名单、组织与区域表现|
|经销商个人|岗位×课程主题、个人进度、课程考试、同公司基准、成长档案|
|经销商公司|最多三家公司横向对比、团队覆盖、公司×主题、岗位与人员下钻|
|美利肯员工|内部部门与岗位、必修任务达成、部门比较、员工档案|
|区域对比|区域×课程主题、学习覆盖、任务/考试表现、区域人员|

模拟人员共360位：300位经销商人员归属12家经销商公司，60位员工归属独立内部组织。支持区域、企业、身份、部门、岗位组合筛选。公司、部门、区域比率按实际任务数加权计算。

在线演示：[学习成长驾驶舱](https://leo131496.github.io/CenterDashboard/)。详细设计见 [第二版多维看板方案](docs/第二版多维看板方案.md)。

## 保留业务专题

|主题|内容|
|---|---|
|课程分析|学习人数/时长、修读类型、课程分类、学习状态、任务进度与学员明细|
|智库分析|阅读、检索、热词、零结果搜索、投稿、草稿、附件类型、收藏及评论|
|考试分析|通过/首次通过、平均分、成绩分布、待考/重考、试卷表现、错题解析|
|学员成长|学员/企业排行、学分/成长值、等级分布、勋章、降级记录与学员关怀|
|内容治理|待审核/超时、投稿结果、附件解析状态、修改日志、协议与首页埋点规划|

所有主题支持日期、区域、企业、学员身份、员工部门和人员岗位筛选；明细支持搜索、分类筛选、数值排序、分页和CSV导出。指标卡可查看口径及相关记录；图表节点支持悬停和键盘聚焦；支持桌面与移动屏幕。

## 统计原则

- 行为量：所选区间内实际发生的事件。
- 课程/考试：所选区间内新分配的任务，跟踪截至期末的学习、考试结果。完成与考试漏斗使用同一批次。
- 等级/勋章/待审核：截至期末的存量；配置数量明确标注全局快照。
- 考试按学员 × 试卷去重；多次考试保留答卷明细，以最新成绩判断通过；首次通过只奖励一次。
- 环比为紧邻的前一个等长区间；比率比较显示百分点。
- 导出保留日期、人群范围及数据性质；明细导出包含全部匹配记录，保留表格搜索和分类条件。

详细方案见 [第一版功能方案](docs/第一版功能方案.md)、[功能核验与覆盖](docs/功能核验与覆盖.md)、[指标与接入说明](docs/指标与接入说明.md)。也可在Demo左下角查看「功能覆盖与指标说明」。

## 验证

```sh
npm test
```

14项数据测试验证个人/公司/员工归属隔离、部门与岗位筛选、组织汇总守恒、热力图样本量、任务漏斗、重考去重、奖励幂等、历史快照、趋势与汇总一致、零分母、内容治理分区及环比区间。

浏览器回归需要 Playwright 与 Chrome/Chromium：

```sh
npm install
npx playwright install chromium
npm run dev
npm run test:ui
```

`CHROME_PATH` 可指定已安装的Chrome；`DEMO_URL` 可指定远端部署地址。浏览器回归覆盖10个桌面/移动视图、三家公司比较及取消、公司到个人下钻、员工部门/岗位筛选、CSV范围和现有专题。截图保存在 `test-results/`，不会提交到仓库。

## 发布

应用可直接使用 GitHub Pages 静态发布，无需构建。在仓库 **Settings → Pages → Source** 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`。后续更新主分支即可重新发布。提交前运行 `npm test` 核对指标一致性。

## 接入边界

本仓库提供可评审的多维产品方案与前端交互，不包含接口服务、真实账号、租户数据、登录状态或权限凭证。所有审核、消息、催学和等级变更均不在Demo执行范围内。

正式接入需确认角色权限、人员与企业归属、学习完成/时长定义、试卷与考试批次、学分/成长值关系、等级和勋章规则，并补齐行为埋点。后台当前降级配置与手册描述存在差异，已在文档中记录，不能直接照搬手册的周期性说明。
