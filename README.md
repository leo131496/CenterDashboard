# 美利肯学习成长中心数据看板

学习成长中心新增「数据看板」的 V2.5.1 多维交互 Demo。已登录核验现有后台五组菜单、11个页面，并结合《美利肯 学习成长中心 详细操作手册》V1.2整理功能范围。

**所有学员、企业、数值、规则及流水均为模拟数据。未连接真实业务接口，未修改原后台。** 课程与内容名称仅用于展示业务场景。

## 运行

直接打开 `index.html` 即可离线演示。推荐使用 Node.js 20+：

```sh
npm run dev
```

访问 http://127.0.0.1:4173 。应用运行不需要安装依赖、不访问外部CDN。页面可部署在任意静态服务器或 GitHub Pages 的仓库子目录。

## V2.5 经销商人员筛选

顶部先选择经销商公司，再打开「经销商人员」：显示该公司的人员姓名和唯一编号，可先按姓名或编号搜索，再选择一位人员。输入搜索词仅过滤候选名单；选中后，指标、图表、人员明细与导出同步使用该人员范围。选择「全部人员」恢复公司全员视图。

切换公司或身份、切换管理视角、重置筛选会清除人员选择；结束日期早于该人员注册日时也自动清除。美利肯员工仍使用销售区域筛选。单图条件只能进一步缩小全局人员范围，不能扩展到其他人员。CSV注明所选姓名和人员编号，姓名及业务记录均为模拟数据。

## V2.2 图表切换与独立筛选

24张图表均有「图表类型」「筛选」「导出」入口，按数据含义提供可用样式：

|图表内容|可选样式|
|---|---|
|成绩、考试状态、修读类型、学习状态、等级、审核/解析分布|环形图、饼图、条形图、柱状图、数据表|
|参与、学习完成、知识使用趋势|折线图、面积图、柱状图、数据表|
|公司/销售区域排行、主题完成率、关键词、附件类型、学分来源、勋章覆盖|条形图、柱状图、数据表|
|公司或销售区域 × 学习主题|热力图、数据表|

- 每张图独立保存样式偏好到当前浏览器；刷新后恢复，不进行账号或设备同步。浏览器禁止存储时，仍支持本次切换。
- 单图筛选继承顶部全局范围，仅进一步缩小日期和人群。按图表业务提供身份、企业、员工销售区域，以及课程分类/具体课程、附件类型、关键词等条件。
- 点击「应用到此图」后标注「仅此图」和生效条件，其他图表、顶部指标与页面明细不变。「清除」或「重置此图筛选」仅清除此图条件，不重置样式。
- 单图条件在本次页面会话内保留，刷新页面清除。顶部范围变化时同步收窄越界日期并清除冲突人群，图内提示已调整。
- 单图导出使用图内数据与条件。公司/销售区域条形图可查看团队，再打开个人档案，任务与考试继承该图范围。

## 统计原则

- 行为量：所选区间内实际发生的事件。
- 课程/考试：所选区间内新分配的任务，跟踪截至期末的学习、考试结果。完成与考试漏斗使用同一批次。
- 等级/勋章/待审核：截至期末的存量；配置数量明确标注全局快照。
- 考试按学员 × 试卷去重；多次考试保留答卷明细，以最新成绩判断通过；首次通过只奖励一次。
- 环比为紧邻的前一个等长区间；比率比较显示百分点。
- 导出保留日期、人群范围及数据性质；明细导出包含全部匹配记录，保留表格搜索和分类条件。

## 发布

应用可直接使用 GitHub Pages 静态发布，无需构建。在仓库 **Settings → Pages → Source** 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`。后续更新主分支即可重新发布。提交前运行 `npm test` 核对指标一致性。

## 接入边界

本仓库提供可评审的多维产品方案与前端交互，不包含接口服务、真实账号、租户数据、登录状态或权限凭证。所有审核、消息、催学和等级变更均不在Demo执行范围内。

正式接入需确认角色权限、人员与企业归属、学习完成/时长定义、试卷与考试批次、学分/成长值关系、等级和勋章规则，并补齐行为埋点。后台当前降级配置与手册描述存在差异，已在文档中记录，不能直接照搬手册的周期性说明。
